Topic 1: JavaScript Objects

Easy Explanation

Objects are like "containers" that hold related information about something, like a person or a car. They use key-value pairs: the "key" is like a label (e.g., "name"), and the "value" is the data (e.g., "Emma"). Objects can hold strings, numbers, booleans, arrays, functions, or even other objects!

Why use objects? They make code organized and real-world-like. Instead of separate variables like studentName and studentAge, everything is in one student object.

In-Depth Explanation

Objects are mutable (changeable) and passed by reference (changing one affects copies). Keys are always strings (or symbols), but you can access them with dot notation (obj.name) or brackets (obj["name"]) – brackets are great for dynamic keys.

Methods are functions inside objects. Use this to refer to the object itself inside methods. Objects can be nested (objects inside objects) for complex data, like a student with an "address" object.

Common pitfalls: Forgetting to use new Object() or literals {}; confusing objects with arrays (arrays are ordered, objects are not); mutating originals when copying (use {...obj} for shallow copy).

Tip: Use Object.keys(obj) to get all keys, Object.values(obj) for values, Object.entries(obj) for pairs.

Examples

// Basic object
const student = { name: "Emma", age: 21, greet: function() { return `Hi, I'm ${this.name}!`; } };
console.log(student.greet()); // "Hi, I'm Emma!"

// Nested object
const detailedStudent = {
  name: "Liam",
  address: { city: "Vancouver", zip: "V5K 0A1" },
  hobbies: ["gaming"]
};
console.log(detailedStudent.address.city); // "Vancouver"

// Copy and modify (shallow copy)
const updated = { ...student, age: 22 };
console.log(updated.age); // 22
console.log(student.age); // 21 (original unchanged)

Topic 2: .map() – Transform Arrays

Easy Explanation

array.map() creates a new array by applying a function to each item. It's like "for each item, change it this way and collect the results." Great for transforming data without changing the original array.

In-Depth Explanation

map(callback) where callback gets (item, index, array). Returns new array of same length. Use arrow functions for short code. For objects, spread ({...item, newProp: value}) to modify without mutating. Chains well with filter/reduce.

Common pitfalls: Mutating items inside map (bad!); forgetting it returns new array; using map for side effects (use forEach instead).

Tip: If you need to flatten, use flatMap(). For async, use Promise.all with map.

Examples

// Basic: Double ages
const agesDoubled = students.map(s => s.age * 2);
console.log(agesDoubled); // [42, 38, 44, 40, 42]

// With objects: Add "passed" property
const withStatus = students.map(s => ({ ...s, passed: s.grade >= 70 }));
console.log(withStatus[3].passed); // false

// Using index
const numbered = students.map((s, i) => `${i+1}. ${s.name}`);
console.log(numbered); // ["1. Emma", ...]

Topic 3: .filter() – Select Items

Easy Explanation

array.filter() creates a new array with only items that "pass" a test (callback returns true). Like "keep only these."

In-Depth Explanation

filter(callback) with (item, index, array). Returns subset. Empty if none pass. Great for queries. Combine conditions with &&/||.

Common pitfalls: Modifying items inside filter; confusing with find() (which returns first match).

Tip: For unique, use Set with filter. For complex, use some/every for checks.

Examples

// Basic: Ages over 20
const adults = students.filter(s => s.age > 20);
console.log(adults.length); // 3

// Multiple conditions
const highToronto = students.filter(s => s.grade > 80 && s.city === "Toronto");
console.log(highToronto.map(s => s.name)); // ["Emma", "Olivia"]

// With array property
const coders = students.filter(s => s.hobbies.includes("coding"));
console.log(coders.map(s => s.name)); // ["Emma", "Noah"]

Topic 4: .reduce() – Combine into One

Easy Explanation

array.reduce() "reduces" the array to one value by combining items step-by-step. Like summing or finding max.

In-Depth Explanation

reduce(callback, initialValue) with callback(accumulator, item, index, array). Accumulator starts as initialValue (or first item). Versatile: sum, group, flatten, etc. For objects, init as {}.

Common pitfalls: Forgetting initialValue (skips first); mutating accumulator wrongly; complex callbacks hard to debug.

Tip: Break complex reduces into steps; use for custom sorts or counts.

Examples

// Sum ages
const totalAge = students.reduce((sum, s) => sum + s.age, 0);
console.log(totalAge / students.length); // 20.6

// Max grade student
const top = students.reduce((best, s) => s.grade > best.grade ? s : best, students[0]);
console.log(top.name); // "Ava"

// Group by city
const groups = students.reduce((obj, s) => {
  obj[s.city] = obj[s.city] || [];
  obj[s.city].push(s);
  return obj;
}, {});
console.log(groups.Toronto.length); // 2

Topic 5: localStorage – Browser Storage

Easy Explanation

localStorage saves data in the browser, even after refresh/close. Like a mini-database for your site. Stores strings, so use JSON for objects/arrays.

In-Depth Explanation

Methods: setItem(key, value), getItem(key), removeItem(key), clear(). 5MB limit per site. Sync, no expiry. Use try-catch for errors. For complex, consider IndexedDB.

Common pitfalls: Forgetting JSON.stringify/parse; quota exceeded; private mode disables.

Tip: Check if getItem returns null; use for carts, settings, offline data.

Examples

// Save
localStorage.setItem("students", JSON.stringify(students));

// Load
const loaded = JSON.parse(localStorage.getItem("students") || "[]");
console.log(loaded[0].name); // "Emma"

// Remove one
localStorage.removeItem("students");
console.log(localStorage.getItem("students")); // null

  2. Save our students array. Refresh console, load it.
  3. Clear localStorage. Check if "students" is null.

Combining Everything: Chaining + In-Depth Topics

Chain methods: students.filter(...).map(...).reduce(...)

// Advanced chain: Average age of coders from Toronto
const avg = students
  .filter(s => s.city === "Toronto" && s.hobbies.includes("coding"))
  .map(s => s.age)
  .reduce((sum, a, i, arr) => sum + a / arr.length, 0);
console.log(avg); // 21 (only Emma)

In-Depth Topics (Advanced End)

  • Object Prototypes: All objects inherit from Object.prototype. Add methods via prototype for classes.
  • Async Map/Filter: Use await Promise.all(array.map(async ...)) for promises.
  • Reduce for State Management: Like Redux: newState = reduce(actions, initial).
  • localStorage Events: window.addEventListener("storage") for cross-tab sync.
  • Performance: For large arrays, reduce can be O(n), but avoid nested loops inside.

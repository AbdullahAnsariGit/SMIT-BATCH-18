1. Callbacks

The original way to handle asynchronous code

A callback is a function passed as an argument to another function. It gets executed after the first function finishes its work.

Used heavily before Promises existed. Still common in event listeners, setTimeout, and older Node.js modules.

EXAMPLE: setTimeout Callback 📋 Copy 
function fetchData(callback) {
    console.log("Fetching data...");
    
    setTimeout(() => {
        const data = { id: 1, name: "Alex Rivera" };
        callback(data);           // ← Callback is called here
    }, 1500);
}

fetchData((result) => {
    console.log("✅ Data received:", result);
});

Callback Hell happens when callbacks are nested 4–5 levels deep (also called “Pyramid of Doom”).

REAL-WORLD USE CASE

Form Validation + Payment Gateway

Stripe, PayPal, and Razorpay still use callbacks for success/failure handling:

  • stripe.confirmCardPayment(..., (result) => { ... })
  • Google Maps API: map.addListener('click', callback)
  • Node.js file system: fs.readFile(path, callback)

2. API Calls

Fetching data from servers in real time

An API call is when your JavaScript talks to a backend server (REST, GraphQL, etc.). Modern browsers use the fetch() API.

Old Way (Callback-based) 

const xhr = new XMLHttpRequest();
xhr.open("GET", "https://jsonplaceholder.typicode.com/users/1");
xhr.onload = function() {
    if (xhr.status === 200) {
        console.log(JSON.parse(xhr.responseText));
    }
};
xhr.send();

Modern Way (fetch + Promise) 

fetch("https://jsonplaceholder.typicode.com/users/1")
  .then(res => res.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));

REAL-WORLD USE CASE

Weather App • E-commerce Product Search • Social Media Feed Refresh • Banking Dashboard (real-time balance)

Every time you scroll Instagram or click “Buy Now” on Amazon, an API call is happening behind the scenes.

3. Promises

A cleaner way to handle async operations (ES6)

A Promise is an object that represents the eventual completion (or failure) of an asynchronous operation.

Creating & Consuming a Promise 📋 Copy 
const getUser = () => {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            const success = true;
            if (success) resolve({ name: "Sarah Chen", role: "Designer" });
            else reject("User not found");
        }, 1200);
    });
};

// Using it
getUser()
    .then(user => console.log("✅", user))
    .catch(error => console.error("❌", error));

4. Async / Await

Syntactic sugar over Promises — code that looks synchronous (ES8)

Async/Await Example (Cleanest way) 📋 Copy 
async function loadUserProfile() {
    try {
        const res = await fetch("https://jsonplaceholder.typicode.com/users/1");
        const user = await res.json();
        
        console.log("User loaded:", user);
        
        // You can await multiple times in sequence
        const posts = await fetch(`https://jsonplaceholder.typicode.com/posts?userId=${user.id}`);
        const postData = await posts.json();
        
        return { user, posts: postData };
    } catch (err) {
        console.error("Something went wrong", err);
    }
}

// Call it
loadUserProfile().then(result => console.log(result));

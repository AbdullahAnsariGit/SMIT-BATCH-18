01

MongoDB kya hai?

MongoDB ek NoSQL, document-oriented database hai. Ismein data traditional rows aur columns ke bajaye JSON-like documents ke form mein store hota hai.

MongoDB internally BSON (Binary JSON) format use karta hai.

user document JSON 
{
  "name": "Ali",
  "age": 20,
  "email": "ali@example.com",
  "skills": [
    "JavaScript",
    "React",
    "Node.js"
  ]
}

MongoDB Structure

MongoDB mein data kuch is tarah organize hota hai:

Database Application ka main data container
↓
Collection Documents ka group
↓
Document Individual data record
↓
Field Document ki individual property
03

MongoDB kyun use karte hain?

⚡

Flexible

MongoDB ka document structure flexible hota hai, isliye changing requirements ke saath data model evolve karna easier ho sakta hai.

📄

Document Based

Data JSON-like documents mein store hota hai, jo JavaScript applications ke liye natural feel hota hai.

📈

Scalable

MongoDB large workloads ke liye horizontal scaling capabilities provide karta hai.

🚀

Developer Friendly

Node.js aur JavaScript ecosystem ke saath MongoDB commonly use kiya jata hai.

db.students.find({
  name: "Ali"

Update Document

db.students.updateOne(
  { name: "Ali" },

db.students.deleteOne({

SQL vs NoSQL

SQL databases relational tables use karti hain, jabke NoSQL databases different data models use kar sakti hain. MongoDB ek document-oriented NoSQL database hai.

SQL MongoDB / NoSQL
Table Collection
Row Document
Column Field
Relational Document-oriented
Usually predefined schema Flexible document structure
JOINs Embedding / References
SQL Query MongoDB Query API

SQL Query

SELECT *
FROM users
WHERE age > 18;

MongoDB Query

db.users.find({
  age: { $gt: 18 }
});

11

Limitations / Considerations

⚠️ MongoDB har project ke liye best nahi hai.

Agar application mein highly relational data aur complex relationships hain, relational SQL database better fit ho sakta hai.

Database select karte waqt application ki requirements, data relationships, transactions aur scalability ko consider karna chahiye.

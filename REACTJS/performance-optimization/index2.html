React Performance: memo, useMemo & useCallback

Detailed notes + Custom memo implementation

HOC React.memo

React.memo is a Higher-Order Component that memoizes a functional component. It prevents the component from re-rendering if its props have not changed (shallow comparison by default).

How it works

  • Wraps a component and caches the last rendered result.
  • On next render, React compares previous props with new props using Object.is (shallow).
  • If props are the same → skips re-render and reuses the previous result.
  • If props changed → re-renders normally.

Basic Syntax

import React from 'react';

const MyComponent = React.memo(function MyComponent({ name, age }) {
  console.log('Rendered!');
  return <div>{name} is {age} years old</div>;
});

// Or with arrow function
const MyComponent = React.memo(({ name, age }) => {
  return <div>{name} is {age} years old</div>;
});

Custom Comparison Function (optional)

const MyComponent = React.memo(
  ({ user }) => <div>{user.name}</div>,
  (prevProps, nextProps) => {
    // return true  → props are equal → SKIP re-render
    // return false → props different → RE-RENDER
    return prevProps.user.id === nextProps.user.id;
  }
);
Use Cases:
  • Pure presentational components that receive the same props often.
  • List items in large lists (TodoItem, UserCard).
  • Expensive-to-render components whose props rarely change.
  • When a parent re-renders frequently but the child doesn’t need to.

⚠ React.memo only does a shallow comparison of props. Objects, arrays and functions are compared by reference.

Custom Custom memo Implementation

Below is a simplified version of how React.memo works under the hood. It is useful for learning and for environments where you want a lightweight alternative.

1. Shallow Equality Helper

function shallowEqual(objA, objB) {
  if (Object.is(objA, objB)) return true;

  if (
    typeof objA !== 'object' || objA === null ||
    typeof objB !== 'object' || objB === null
  ) {
    return false;
  }

  const keysA = Object.keys(objA);
  const keysB = Object.keys(objB);

  if (keysA.length !== keysB.length) return false;

  for (let i = 0; i < keysA.length; i++) {
    const key = keysA[i];
    if (
      !Object.prototype.hasOwnProperty.call(objB, key) ||
      !Object.is(objA[key], objB[key])
    ) {
      return false;
    }
  }

  return true;
}

2. Custom memo HOC

function memo(Component, areEqual = shallowEqual) {
  // This will hold the previous props and the last rendered element
  let prevProps = null;
  let prevResult = null;

  function MemoizedComponent(props) {
    // First render or props changed → render normally
    if (prevProps === null || !areEqual(prevProps, props)) {
      prevProps = props;
      prevResult = Component(props);   // call the original component
      return prevResult;
    }

    // Props are equal → return the cached result (skip re-render)
    return prevResult;
  }

  // Nice name for React DevTools
  MemoizedComponent.displayName = `Memo(${Component.displayName || Component.name || 'Component'})`;

  return MemoizedComponent;
}

3. Usage Example

// Normal component
function UserCard({ name, age }) {
  console.log('UserCard rendered');
  return (
    <div>
      <h3>{name}</h3>
      <p>Age: {age}</p>
    </div>
  );
}

// Memoized version
const MemoizedUserCard = memo(UserCard);

// With custom comparison
const MemoizedUserCard2 = memo(UserCard, (prev, next) => {
  return prev.name === next.name; // only care about name
});

// In parent
function App() {
  const [count, setCount] = React.useState(0);

  return (
    <div>
      <button onClick={() => setCount(c => c + 1)}>Count: {count}</button>
      {/* This will NOT re-render when count changes */}
      <MemoizedUserCard name="Alice" age={25} />
    </div>
  );
}

4. More Complete Version (supports children & ref forwarding idea)

function memo(Component, areEqual = shallowEqual) {
  let prevProps = null;
  let prevElement = null;

  function Memoized(props) {
    if (prevProps !== null && areEqual(prevProps, props)) {
      return prevElement; // reuse previous React element
    }

    prevProps = props;
    prevElement = React.createElement(Component, props);
    return prevElement;
  }

  Memoized.displayName = `Memo(${Component.displayName || Component.name || 'Component'})`;
  return Memoized;
}
Notes about the custom implementation:
  • This is a simplified educational version. Real React.memo is more sophisticated (handles context, refs, concurrent features, etc.).
  • It works by caching the previous props and the previous render result.
  • You can pass a custom areEqual function just like React.memo.
  • In real projects always prefer the official React.memo.

Hook useMemo

useMemo memoizes the result of a calculation. It only recomputes when one of its dependencies changes.

Syntax

const memoizedValue = useMemo(() => {
  return computeExpensiveValue(a, b);
}, [a, b]);

Example – Expensive Calculation

function ProductList({ products, filterText }) {
  const filteredProducts = useMemo(() => {
    console.log('Filtering...');
    return products.filter(p =>
      p.name.toLowerCase().includes(filterText.toLowerCase())
    );
  }, [products, filterText]);

  return (
    <ul>
      {filteredProducts.map(p => <li key={p.id}>{p.name}</li>)}
    </ul>
  );
}

Example – Stable Object Reference

const options = useMemo(() => ({
  userId,
  theme: 'dark'
}), [userId]);

// Now safe to pass to a React.memo child
<Child options={options} />
Use Cases:
  • Expensive calculations (filter, sort, heavy math).
  • Creating objects/arrays that are passed as props to memoized children.
  • Derived data that depends on other state/props.

Hook useCallback

useCallback memoizes a function. It returns the same function instance as long as dependencies stay the same.

Syntax

const memoizedFn = useCallback(() => {
  doSomething(a, b);
}, [a, b]);

useCallback(fn, deps) ≈ useMemo(() => fn, deps)

Example – Stable Callback for Memoized Child

function Parent() {
  const [count, setCount] = useState(0);
  const [text, setText] = useState('');

  const handleClick = useCallback(() => {
    setCount(c => c + 1);
  }, []); // stable forever

  return (
    <>
      <input value={text} onChange={e => setText(e.target.value)} />
      <Child onClick={handleClick} />
    </>
  );
}

const Child = React.memo(({ onClick }) => {
  console.log('Child rendered');
  return <button onClick={onClick}>Click me</button>;
});
Use Cases:
  • Passing callbacks to React.memo children.
  • Functions used in dependency arrays of other hooks.
  • Event handlers that should keep the same reference.

Best Practices

  • Measure first — Use React DevTools Profiler before adding memoization.
  • Shallow comparison only → always memoize objects/arrays/functions passed to memoized children.
  • Don’t overuse. Memoization has a small cost and can make code harder to read.
  • Prefer official React.memo in real apps. The custom version is mainly for learning.
  • Always include correct dependencies to avoid stale closures.

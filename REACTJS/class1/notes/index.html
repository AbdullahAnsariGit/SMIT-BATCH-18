1. Introduction to React.js

React.js is one of the most popular JavaScript libraries used for building modern user interfaces and web applications.

React was developed by Facebook (Meta) and is used in:

  • Facebook
  • Instagram
  • Netflix
  • Airbnb
  • WhatsApp Web

React helps developers create fast, scalable, and interactive web applications.

3. Understanding the DOM

DOM stands for Document Object Model.

It represents the structure of a webpage as a tree.

DOM Manipulation Example


<h1 id="title">Hello</h1>

<script>
  document.getElementById("title").innerText = "Welcome";
</script>

4. React vs Plain JavaScript DOM

Feature React Plain JavaScript
DOM Virtual DOM Real DOM
Performance Fast Slower
Code Reusability High Low
Scalability Excellent Limited
Maintainability Easy Difficult

Plain JavaScript Example


<button id="btn">Increment</button>
<p id="count">0</p>

<script>
  let count = 0;

  document.getElementById("btn")
  .addEventListener("click", () => {
    count++;
    document.getElementById("count").innerText = count;
  });
</script>

React Example


import { useState } from "react";

function Counter() {

  const [count, setCount] = useState(0);

  return (
    <div>
      <p>{count}</p>

      <button onClick={() => setCount(count + 1)}>
        Increment
      </button>
    </div>
  );
}

8. JSX in React

JSX stands for JavaScript XML.

It allows writing HTML inside JavaScript. 


function App() {
  return <h1>Hello React</h1>;
}

JSX Rules

  • Return one parent element
  • Use className instead of class
  • Close all tags

9. Components in React

Functional Component


function Welcome() {
  return <h1>Welcome</h1>;
}

Props Example


function User(props) {
  return <h1>{props.name}</h1>;
}

function App() {
  return <User name="Ali" />;
}

State Example


import { useState } from "react";

function Counter() {

  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  );
}

10. Hooks in React

Common Hooks

Hook Purpose
useState State Management
useEffect Side Effects
useContext Global Data
useRef DOM Reference

useEffect Example


import { useEffect } from "react";

function App() {

  useEffect(() => {
    console.log("Component Mounted");
  }, []);

  return <h1>Hello</h1>;
}

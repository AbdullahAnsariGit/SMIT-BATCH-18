Bootstrap concepts — step-by-step guide

A beginner-friendly guide demonstrating key concepts (breakpoints, colors, containers, spacing, flexbox, components) using plain HTML & CSS. Each section includes a short explanation and a live example.

1. Breakpoints (responsive rules)

Breakpoints let you change styles when the viewport reaches a certain width. This is mobile-first: write base styles for small screens, then add @media (min-width: ...) for larger screens.

Resize the window to see text & badge change.
@media (min-width: 768px) {
  .sidebar { display:block; }
}
  1. Define base (mobile) styles first.
  2. Add media queries for sm, md, lg, xl as needed.
  3. Use layout changes, font sizes, visibility toggles at breakpoints.

2. Colors

3. Containers

Containers set a readable max width and horizontal padding. They let your content breathe on large screens while staying full-width on small screens.

Example: this block is a .container-md — it will center and stop expanding past a defined max width. 
.container{ width:100%; padding-left:1rem; padding-right:1rem; }
.container-md{ max-width:720px; margin:0 auto; }

4. Margin (spacing outside an element)

Margins create space between elements. Utility classes let you add margin quickly without writing new CSS every time.

I have .mb-3 (margin-bottom)
I follow the spaced box
.mb-3{ margin-bottom: 1rem; }

Tip: use vertical margin utilities (mt, mb) for consistent rhythm.

5. Padding (space inside an element)

Padding increases the inner space of a box. Use utilities like .p-2, .px-2, .py-2 for quick adjustments.

Card with .p-3

Content inside has internal spacing.

.p-3{ padding:1rem; }

6. Flexbox

Flexbox provides powerful alignment and distribution tools for 1-dimensional layouts (rows or columns).

.justify-between{ justify-content: space-between; }
.align-center{ align-items:center; }

Common patterns: horizontal navs, spacing between items, vertical centering.

1. What is a Callback Function?

A callback is a function that is passed as an argument to another function and is executed after some operation is completed.

Simple Analogy:

Think of ordering food at a restaurant:

  • You give your order to the waiter (main function)
  • The waiter goes to the kitchen and prepares food (asynchronous task)
  • When food is ready, the waiter calls you (callback function) to serve it
// Basic Callback Example

function greet(name) {
    console.log("Hello, " + name + "!");
}

function processUserInput(callback) {
    const name = "Alice";
    callback(name);        // Calling the callback
}

processUserInput(greet);   // Output: Hello, Alice!

2. Why Do We Need Callbacks?

JavaScript is single-threaded and uses an event-driven, non-blocking I/O model. Callbacks allow us to handle asynchronous operations without blocking the main thread.

Common Use Cases:

  • setTimeout / setInterval
  • Event listeners (click, scroll, etc.)
  • Fetching data from server (AJAX / fetch)
  • File reading (Node.js fs module)
  • Array methods: forEach, map, filter, reduce

3. Synchronous vs Asynchronous Callbacks

Synchronous Callback Example

function calculate(a, b, callback) {
    const result = a + b;
    callback(result);           // executed immediately
}

calculate(5, 10, function(result) {
    console.log("Sum is:", result);   // Output: Sum is: 15
});

Asynchronous Callback Example (using setTimeout)

console.log("Start");

function fetchData(callback) {
    setTimeout(function() {
        const data = "Data loaded from server";
        callback(data);
    }, 2000);   // simulates 2 second delay
}

fetchData(function(result) {
    console.log(result);   // runs after 2 seconds
});

console.log("End");
// Output order: 
// Start
// End
// Data loaded from server

4. Callback as Named Function vs Anonymous Function

// 1. Named Function Callback
function showResult(result) {
    console.log("Result:", result);
}

function add(a, b, callback) {
    callback(a + b);
}

add(7, 8, showResult);

// 2. Anonymous Function Callback
add(10, 20, function(result) {
    console.log("Anonymous Result:", result);
});

5. Passing Multiple Callbacks (Error First Pattern)

Common in Node.js style callbacks.

function divide(a, b, successCallback, errorCallback) {
    if (b === 0) {
        errorCallback("Cannot divide by zero!");
        return;
    }
    successCallback(a / b);
}

divide(10, 2, 
    function(result) { console.log("Success:", result); },
    function(error) { console.log("Error:", error); }
);

divide(10, 0, 
    function(result) { console.log("Success:", result); },
    function(error) { console.log("Error:", error); }
);

6. Real-World Example: Simulating API Call

function simulateAPICall() {
    const output = document.getElementById("apiOutput");
    output.textContent = "Fetching data...";

    setTimeout(() => {
        const users = [
            { id: 1, name: "John" },
            { id: 2, name: "Sarah" }
        ];
        
        displayUsers(users);   // Callback
    }, 1500);
}

function displayUsers(users) {
    let html = "<h3>Users:</h3>";
    users.forEach(user => {
        html += `<p>ID: ${user.id}, Name: ${user.name}</p>`;
    });
    document.getElementById("apiOutput").innerHTML = html;
}

7. Array Methods Using Callbacks

forEach()

const numbers = [1, 2, 3, 4, 5];

numbers.forEach(function(num, index) {
    console.log(`Index ${index}: ${num}`);
});

map()

const doubled = numbers.map(function(num) {
    return num * 2;
});
console.log(doubled); // [2, 4, 6, 8, 10]

8. Callback Hell (Pyramid of Doom)

When callbacks are nested deeply, code becomes hard to read and maintain.

getUser(1, function(user) {
    getPosts(user.id, function(posts) {
        getComments(posts[0].id, function(comments) {
            // Deep nesting...
            console.log(comments);
        });
    });
});

Solution: Use Promises or async/await (future topic)

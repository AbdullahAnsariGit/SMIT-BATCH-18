File Uploads with Multer in Express.js

A practical guide to receiving multipart/form-data files in an Express application, validating uploads, storing files, and handling upload errors safely.

1. Overview

Multer is middleware for handling multipart/form-data, the encoding normally used when an HTML form uploads files.

It parses the incoming request and exposes uploaded files through:

  • req.file — when one file is uploaded.
  • req.files — when multiple files are uploaded.
  • req.body — for accompanying text fields.
Important: Multer should normally be attached only to routes that actually accept uploads. Avoid installing it globally as app.use(upload.any()).

2. Installation

npm install multer express

Typical project structure:

project/
├── uploads/
├── src/
│   ├── routes/
│   ├── controllers/
│   ├── middleware/
│   └── app.js
└── package.json

3. Basic Setup

const express = require("express");
const multer = require("multer");

const app = express();

const upload = multer({
  dest: "uploads/"
});

app.post("/upload", upload.single("file"), (req, res) => {
  console.log(req.file);
  console.log(req.body);

  res.json({
    message: "File uploaded successfully",
    file: req.file
  });
});

app.listen(3000, () => {
  console.log("Server running on port 3000");
});

The field name in the client must match single("file").

4. Upload a Single File

app.post(
  "/profile",
  upload.single("avatar"),
  (req, res) => {
    console.log(req.file);

    res.json({
      filename: req.file.filename,
      originalName: req.file.originalname,
      mimeType: req.file.mimetype,
      size: req.file.size
    });
  }
);

Important req.file properties:

Property Description
fieldname Name of the multipart form field.
originalname Original filename supplied by the client.
encoding Transfer encoding.
mimetype MIME type reported by the client.
size File size in bytes.
destination Destination directory when disk storage is used.
filename Stored filename when disk storage is used.
path Full stored path when disk storage is used.
buffer File contents when memory storage is used.

5. Upload Multiple Files

Using array()

app.post(
  "/gallery",
  upload.array("images", 5),
  (req, res) => {
    console.log(req.files);

    res.json({
      count: req.files.length,
      files: req.files
    });
  }
);

Here, images is the field name and at most 5 files are accepted.

Using fields()

const uploadFields = upload.fields([
  { name: "avatar", maxCount: 1 },
  { name: "documents", maxCount: 3 }
]);

app.post("/account", uploadFields, (req, res) => {
  console.log(req.files.avatar);
  console.log(req.files.documents);

  res.json({ message: "Uploaded" });
});

6. Text Fields + Files

Multer also parses regular multipart text fields.

app.post(
  "/product",
  upload.single("image"),
  (req, res) => {
    const { name, price, description } = req.body;

    console.log(name);
    console.log(price);
    console.log(description);
    console.log(req.file);

    res.json({ message: "Product created" });
  }
);

7. Upload Limits

Use limits to prevent unnecessarily large uploads.

const upload = multer({
  dest: "uploads/",
  limits: {
    fileSize: 5 * 1024 * 1024, // 5 MB
    files: 5,
    fields: 20
  }
});
Why limits matter: Upload endpoints can consume disk, memory, bandwidth, and processing resources. Set limits appropriate to your application.

8. File Type Validation

fileFilter can reject files before they are accepted by Multer. Do not blindly trust the browser-provided MIME type for high-security applications; inspect file signatures/content when necessary. 

const allowedTypes = [
  "image/jpeg",
  "image/png",
  "image/webp"
];

const upload = multer({
  dest: "uploads/",
  fileFilter: (req, file, cb) => {
    if (allowedTypes.includes(file.mimetype)) {
      cb(null, true);
    } else {
      cb(new Error("Only JPEG, PNG and WebP images are allowed"));
    }
  }
});

9. Disk Storage

Disk storage gives you control over the destination and generated filename.

const path = require("path");
const multer = require("multer");

const storage = multer.diskStorage({
  destination: (req, file, cb) => {
    cb(null, "uploads/");
  },

  filename: (req, file, cb) => {
    const extension = path.extname(file.originalname);
    const uniqueName = `${Date.now()}-${Math.round(Math.random() * 1e9)}${extension}`;

    cb(null, uniqueName);
  }
});

const upload = multer({
  storage
});
Prefer generated filenames instead of directly using file.originalname. User-controlled filenames can cause collisions or unsafe path handling if used incorrectly.

10. Memory Storage

With memory storage, Multer places the complete file in a Buffer. This can be useful when immediately sending the file to object storage or another service. 

const upload = multer({
  storage: multer.memoryStorage(),
  limits: {
    fileSize: 2 * 1024 * 1024
  }
});

app.post("/upload", upload.single("file"), async (req, res) => {
  const fileBuffer = req.file.buffer;

  // Send fileBuffer to your storage service here.

  res.json({ message: "File received" });
});
Memory warning: Never use memory storage without sensible file-size and request limits. Large or concurrent uploads can consume significant RAM.

11. Error Handling

Multer exposes specific errors through MulterError.

const multer = require("multer");

app.post(
  "/upload",
  (req, res, next) => {
    upload.single("file")(req, res, (err) => {
      if (err instanceof multer.MulterError) {
        return res.status(400).json({
          message: "Upload failed",
          code: err.code
        });
      }

      if (err) {
        return res.status(400).json({
          message: err.message
        });
      }

      next();
    });
  },
  (req, res) => {
    res.json({
      message: "Upload successful",
      file: req.file
    });
  }
);

Common Multer errors

Error code Typical cause
LIMIT_FILE_SIZE File exceeds the configured size.
LIMIT_FILE_COUNT Too many files were submitted.
LIMIT_UNEXPECTED_FILE Unexpected file field or count.
LIMIT_FIELD_COUNT Too many non-file fields.

12. HTML Form

For file uploads, the form must use enctype="multipart/form-data".

<form
  action="http://localhost:3000/upload"
  method="POST"
  enctype="multipart/form-data"
>
  <label>Choose file:</label>

  <input
    type="file"
    name="file"
    accept="image/*"
  />

  <input
    type="text"
    name="title"
    placeholder="File title"
  />

  <button type="submit">Upload</button>
</form>
Field names must match. If Express uses upload.single("file"), the HTML input must use name="file".

13. Security Best Practices

  1. Set fileSize and file-count limits.
  2. Accept only the file types your endpoint actually needs.
  3. Do not trust originalname for filesystem paths.
  4. Generate server-side filenames.
  5. Consider validating file signatures/content, not only MIME types or extensions.
  6. Store uploaded files outside publicly served directories when appropriate.
  7. Use authentication/authorization for private upload endpoints.
  8. Consider malware scanning for user-supplied documents where the threat model requires it.
  9. Use object storage for production-scale media instead of relying solely on local disk.
  10. Use memory storage only when file sizes and concurrency are tightly controlled.

14. Complete Production-Style Example

const express = require("express");
const multer = require("multer");
const path = require("path");

const app = express();

const storage = multer.diskStorage({
  destination: (req, file, cb) => {
    cb(null, "uploads/");
  },

  filename: (req, file, cb) => {
    const ext = path.extname(file.originalname).toLowerCase();
    const filename =
      `${Date.now()}-${Math.round(Math.random() * 1e9)}${ext}`;

    cb(null, filename);
  }
});

const upload = multer({
  storage,

  limits: {
    fileSize: 5 * 1024 * 1024,
    files: 1
  },

  fileFilter: (req, file, cb) => {
    const allowed = [
      "image/jpeg",
      "image/png",
      "image/webp"
    ];

    if (!allowed.includes(file.mimetype)) {
      return cb(new Error("Unsupported file type"));
    }

    cb(null, true);
  }
});

app.post("/api/profile/avatar", (req, res) => {
  upload.single("avatar")(req, res, (err) => {
    if (err instanceof multer.MulterError) {
      return res.status(400).json({
        success: false,
        message: "Upload error",
        code: err.code
      });
    }

    if (err) {
      return res.status(400).json({
        success: false,
        message: err.message
      });
    }

    if (!req.file) {
      return res.status(400).json({
        success: false,
        message: "Avatar is required"
      });
    }

    return res.status(201).json({
      success: true,
      message: "Avatar uploaded successfully",
      file: {
        filename: req.file.filename,
        originalName: req.file.originalname,
        mimeType: req.file.mimetype,
        size: req.file.size,
        path: req.file.path
      }
    });
  });
});

app.listen(3000, () => {
  console.log("API running on http://localhost:3000");
});

15. Quick Reference

Multer API Use case
upload.single("file") One file.
upload.array("files", 5) Multiple files using one field.
upload.fields([...]) Multiple file fields with different names.
upload.none() Multipart form with text fields only.
upload.any() Accept files from any field. Use with caution.
multer.diskStorage() Store files on disk.
multer.memoryStorage() Keep files in memory as buffers.
fileFilter Accept/reject files based on application rules.
limits Control file size, file count, fields, etc.

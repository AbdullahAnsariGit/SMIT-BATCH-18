🚀 API Methods & Request Structure Documentation

GET → Data Fetch

GET method ka use server se data retrieve karne ke liye hota hai.

Key Points:

  • Body nahi hoti
  • Data URL ke through bheja jata hai (Query Params)
  • Safe & idempotent hota hai

Example:

fetch('https://api.example.com/users?page=1&limit=10') .then(res => res.json()) .then(data => console.log(data));

POST → Create Data

POST method new resource create karne ke liye use hota hai.

Key Points:

  • Body required hoti hai
  • Mostly JSON format use hota hai
  • Server par new entry create karta hai

Example:

fetch('https://api.example.com/users', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name: 'Minhaj', email: 'minhaj@gmail.com' }) });

PUT → Full Update

PUT method existing resource ko completely replace karta hai.

Key Points:

  • Pura object bhejna zaroori hota hai
  • Agar koi field missing ho → wo remove ho sakti hai
  • Idempotent hota hai

Example:

fetch('https://api.example.com/users/1', { method: 'PUT', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name: 'Updated Name', email: 'updated@gmail.com' }) });

PATCH → Partial Update

PATCH method sirf specific fields update karta hai.

Key Points:

  • Sirf changed fields bhejte hain
  • Efficient hota hai

Example:

fetch('https://api.example.com/users/1', { method: 'PATCH', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name: 'Only Name Updated' }) });

DELETE → Remove Data

DELETE method resource ko server se remove karta hai.

Key Points:

  • Usually body nahi hoti
  • ID URL me hota hai

Example:

fetch('https://api.example.com/users/1', { method: 'DELETE' });

Headers → Auth & Metadata

Headers request ke sath additional information bhejte hain.

Common Headers:

  • Content-Type → data format define karta hai
  • Authorization → token bhejne ke liye
  • Custom headers → x-api-key waghera

Example:

fetch('/api/private', { headers: { 'Content-Type': 'application/json', 'Authorization': 'Bearer your_token_here' } });

Body → Send Data

Body me data server ko bheja jata hai (mostly POST, PUT, PATCH me).

Types:

  • JSON (most common)
  • FormData (file upload)
  • URL Encoded

JSON Example:

body: JSON.stringify({ name: 'Minhaj' })

FormData Example:

const formData = new FormData(); formData.append('file', fileInput.files[0]); fetch('/upload', { method: 'POST', body: formData });

📊 Summary

  • GET → Data fetch
  • POST → Create
  • PUT → Full update
  • PATCH → Partial update
  • DELETE → Remove
  • Headers → Auth & metadata
  • Body → Data send

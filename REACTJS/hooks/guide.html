React useEffect Hook

1. Introduction

useEffect is a React Hook used to handle side effects in functional components. Side effects include API calls, timers, event listeners, and DOM updates.

It runs after the component renders and helps manage external operations outside React rendering flow.

2. Syntax

Basic structure of useEffect:

useEffect(() => { // side effect logic here }, [dependencies]);

Dependency array controls when effect runs.

3. Mount Phase

Runs only once when component loads.

useEffect(() => { console.log("Component Mounted"); }, []);

✔ Used for initial API calls and setup logic.

4. Update Phase

Runs when specific state or props change.

useEffect(() => { console.log("Value changed"); }, [count]);

✔ Useful for dynamic updates based on state changes.

5. Cleanup Function

Used to prevent memory leaks.

useEffect(() => { const timer = setInterval(() => { console.log("Running..."); }, 1000); return () => { clearInterval(timer); }; }, []);

✔ Used for timers, subscriptions, and event listeners.

6. API Calls

Most common use of useEffect.

useEffect(() => { fetch("https://jsonplaceholder.typicode.com/users") .then(res => res.json()) .then(data => console.log(data)); }, []);

✔ Fetch data when component loads.

7. Rules & Best Practices

✔ Always use dependency array correctly

✔ Always cleanup timers & listeners

✔ Keep effects small and focused

❌ Avoid infinite loops (state update without dependency control)

Summary

useEffect controls side effects in React. It runs on mount, update, and unmount phases depending on dependencies. Proper use improves performance and prevents bugs.

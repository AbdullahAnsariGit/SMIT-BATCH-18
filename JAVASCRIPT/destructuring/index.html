1. Destructuring Assignment (Deep / Nested)

Array Destructuring

// Basic
const numbers = [10, 20, 30];
const [a, b, c] = numbers;

// Skipping values
const [x, , z] = [100, 200, 300]; // x=100, z=300

// Rest operator in arrays
const [first, ...rest] = [1, 2, 3, 4, 5]; // first=1, rest=[2,3,4,5]

Object Destructuring

const user = {
    name: "Minhaj",

// Basic

2. Spread (...) & Rest (...) Operator

Spread Operator

// Arrays
const arr1 = [1, 2, 3];
const arr2 = [...arr1, 4, 5, 6]; // [1,2,3,4,5,6]

const clone = [...arr1]; // Shallow copy

// Objects (most powerful)
const person = { name: "Ali", age: 30 };
const updated = { ...person, age: 31, city: "Lahore" }; // merged + override

// Function arguments
function sum(...numbers) { // Rest in parameters
    return numbers.reduce((a, b) => a + b, 0);
}
sum(1, 2, 3, 4); // 10

Rest vs Spread

  • Rest (...) → Collects remaining elements (used in destructuring & parameters)
  • Spread (...) → Expands / spreads elements (used in arrays/objects/literals)

3. Optional Chaining (?.)

Prevents errors when accessing nested properties that might be null or undefined.

const user = {
    name: "Sara",
    profile: {
        social: {
            twitter: "@sara_dev"
        }
    }
};

// Old way (dangerous)
const twitter = user && user.profile && user.profile.social && user.profile.social.twitter;

// New way - Optional Chaining
const twitterHandle = user?.profile?.social?.twitter;

// With function call
const result = user?.getData?.();

// With array access
const firstSkill = user?.skills?.[0];

// Default value
const city = user?.address?.city ?? "Not available";
Important: ?. stops evaluation if left side is null or undefined.

4. Nullish Coalescing Operator (??)

Returns right-hand side only if left-hand side is null or undefined.

const value1 = null;
const value2 = undefined;
const value3 = 0;
const value4 = false;
const value5 = "";

console.log(value1 ?? "default");     // "default"
console.log(value2 ?? "default");     // "default"
console.log(value3 ?? "default");     // 0        (not falsy!)
console.log(value4 ?? "default");     // false
console.log(value5 ?? "default");     // ""

// Comparison with ||
console.log(0 || "default");          // "default"  ← problem!
console.log(false || "default");      // "default"  ← problem!
Best Practice: Use ?? when you want to treat 0, false, and "" as valid values.

Real-World Combined Example

const config = {
    api: {
        baseURL: "https://api.example.com",
        timeout: 5000
    },
    features: {
        darkMode: false,
        analytics: null
    }
};

const settings = {
    ...config,
    api: {
        ...config.api,
        timeout: 10000
    }
};

// Deep destructuring + optional chaining + nullish
const {
    api: { baseURL, timeout },
    features: { darkMode = false, analytics }
} = settings;

const analyticsEnabled = analytics?.enabled ?? false;

console.log(baseURL, timeout, darkMode, analyticsEnabled);

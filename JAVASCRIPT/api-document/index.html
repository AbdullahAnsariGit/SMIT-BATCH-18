🚀 Fetch API Complete Documentation

1. Basic Fetch Syntax

fetch(url, options) .then(res => res.json()) .then(data => console.log(data)) .catch(err => console.log(err));

Async/Await

const res = await fetch(url, options); const data = await res.json(); console.log(data);

2. HTTP Methods

GET

fetch('https://jsonplaceholder.typicode.com/posts') .then(res => res.json()) .then(data => console.log(data));

POST

fetch('https://jsonplaceholder.typicode.com/posts', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ title: 'Minhaj', body: 'Software Engineer' }) });

PUT

fetch('/api/user/1', { method: 'PUT', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name: 'Updated' }) });

PATCH

fetch('/api/user/1', { method: 'PATCH', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name: 'Partial Update' }) });

DELETE

fetch('/api/user/1', { method: 'DELETE' });

3. Params & Query Params

Query Params

fetch('/api/users?page=1&limit=10');

Path Params

fetch('/api/users/123');

4. Request Body Types

JSON

fetch('/api', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name: 'Minhaj' }) });

FormData (Multipart)

const formData = new FormData(); formData.append('name', 'Minhaj'); formData.append('file', fileInput.files[0]); fetch('/upload', { method: 'POST', body: formData });

URL Encoded

const data = new URLSearchParams(); data.append('name', 'Minhaj'); fetch('/api', { method: 'POST', headers: { 'Content-Type': 'application/x-www-form-urlencoded' }, body: data });

5. Headers & Token

Bearer Token

fetch('/api/private', { headers: { 'Authorization': 'Bearer YOUR_TOKEN' } });

Custom Headers

fetch('/api', { headers: { 'Content-Type': 'application/json', 'x-api-key': '123456' } });

6. Complete Example

async function createUser() { try { const res = await fetch('/api/users?ref=web', { method: 'POST', headers: { 'Content-Type': 'application/json', 'Authorization': 'Bearer token123' }, body: JSON.stringify({ name: 'Minhaj', email: 'minhaj@gmail.com' }) }); if (!res.ok) { throw new Error('Request failed'); } const data = await res.json(); console.log(data); } catch (err) { console.log(err); } }

8. Summary

  • GET → Data fetch
  • POST → Create data
  • PUT → Full update
  • PATCH → Partial update
  • DELETE → Remove data
  • Headers → Auth & metadata
  • Body → Send data

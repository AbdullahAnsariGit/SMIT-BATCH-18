Express.js Filtering & Pagination

A beginner-friendly guide with examples and real-world use cases

1. What Is Filtering?

Filtering means selecting only the data that matches specific conditions. In Express.js, filters are commonly received through URL query parameters.

Example: A store has 1,000 products. A user wants to see only electronics costing less than $500.

Why do we use filtering?

  • Find relevant records quickly.
  • Search products, users, or employees.
  • Filter by category, price, name, or status.
  • Improve the user experience.

Example URL

GET /api/products?category=electronics

Express reads the query parameter using req.query.category.

2. What Is Pagination?

Pagination divides a large collection of records into smaller pages. Instead of returning 1,000 products at once, the API can return 10 products per page.

Example: Page 1 contains products 1–10, page 2 contains products 11–20, and page 3 contains products 21–30.

Why do we use pagination?

  • Reduce the response size.
  • Avoid sending unnecessary data.
  • Make large lists easier to navigate.
  • Reduce memory and network usage when implemented with database-level pagination.

Example URL

GET /api/products?page=2&limit=10

Here, page=2 requests the second page, and limit=10 requests up to 10 records.

4. How Filtering and Pagination Work Together

GET /api/products?category=electronics&maxPrice=500&page=2&limit=10
  1. Read the query parameters.
  2. Filter products by category.
  3. Keep products priced at $500 or less.
  4. Count the matching records.
  5. Return the requested page of results.
Important: Apply filters before pagination. Otherwise, a page may contain fewer matching records than expected.

5. Create an Express.js API

Step 1: Install Express

npm init -y
npm install express

Step 2: Create server.js

const express = require("express");
const app = express();

const products = [
  { id: 1, name: "Laptop", category: "electronics", price: 450 },
  { id: 2, name: "Phone", category: "electronics", price: 300 },
  { id: 3, name: "Desk", category: "furniture", price: 200 },
  { id: 4, name: "Headphones", category: "electronics", price: 80 },
  { id: 5, name: "Chair", category: "furniture", price: 120 }
];

app.get("/api/products", (req, res) => {
  const { category, maxPrice } = req.query;

  const page = Math.max(1, Number(req.query.page) || 1);
  const limit = Math.min(
    100,
    Math.max(1, Number(req.query.limit) || 10)
  );

  // Validate supplied pagination values.
  if (
    (req.query.page !== undefined &&
      (!Number.isInteger(Number(req.query.page)) ||
       Number(req.query.page) < 1)) ||
    (req.query.limit !== undefined &&
      (!Number.isInteger(Number(req.query.limit)) ||
       Number(req.query.limit) < 1)) ||
    (maxPrice !== undefined &&
      (maxPrice.trim() === "" ||
       !Number.isFinite(Number(maxPrice)) ||
       Number(maxPrice) < 0))
  ) {
    return res.status(400).json({
      message: "Invalid query parameters"
    });
  }

  // Step 1: Filter the records.
  const filteredProducts = products.filter(product => {
    const matchesCategory =
      !category || product.category === category;

    const matchesPrice =
      maxPrice === undefined ||
      product.price <= Number(maxPrice);

    return matchesCategory && matchesPrice;
  });

  // Step 2: Calculate pagination.
  const total = filteredProducts.length;
  const totalPages = Math.ceil(total / limit);
  const skip = (page - 1) * limit;

  // Step 3: Get records for the requested page.
  const results = filteredProducts.slice(
    skip,
    skip + limit
  );

  // Step 4: Send the response.
  res.json({
    data: results,
    pagination: {
      total,
      page,
      limit,
      totalPages
    }
  });
});

app.listen(3000, () => {
  console.log("Server running on port 3000");
});

Step 3: Run the server

node server.js

6. Understand the Main Concepts

A. req.query

Express exposes query-string values through req.query. 

/api/products?category=electronics&page=2&limit=10

req.query.category // "electronics"
req.query.page     // "2"
req.query.limit    // "10"

B. Filtering with filter()

const result = products.filter(product =>
  product.category === "electronics"
);

The array's filter() method keeps records that satisfy the specified condition.

C. Calculate the offset

const skip = (page - 1) * limit;
  • Page 1, limit 10: skip 0 records.
  • Page 2, limit 10: skip 10 records.
  • Page 3, limit 10: skip 20 records.

D. Select the current page

const results = filteredProducts.slice(
  skip,
  skip + limit
);

E. Calculate total pages

const totalPages = Math.ceil(total / limit);

If there are 45 matching products and the limit is 10, the result is 5 pages.

8. Database-Level Pagination

In a real application, filtering and pagination should normally be performed by the database rather than by loading the entire collection into server memory.

Example with MongoDB and Mongoose

const filter = {};

if (req.query.category) {
  filter.category = req.query.category;
}

if (req.query.maxPrice !== undefined) {
  filter.price = {
    $lte: Number(req.query.maxPrice)
  };
}

const [data, total] = await Promise.all([
  Product.find(filter)
    .sort({ _id: 1 })
    .skip((page - 1) * limit)
    .limit(limit),

  Product.countDocuments(filter)
]);

res.json({
  data,
  pagination: {
    total,
    page,
    limit,
    totalPages: Math.ceil(total / limit)
  }
});

Place this snippet inside an async Express route. Define the Product model, connect to MongoDB, and validate the parameters before running the database queries.

9. Best Practices

  • Validate page numbers, limits, and filter values.
  • Set a maximum page size, such as 100 records.
  • Filter records before paginating.
  • Use database indexes for common filters and sorting.
  • Use a stable sort order for predictable pagination.
  • Return total counts and pagination metadata.
  • Consider cursor pagination for very large datasets.

10. Final Summary

Filtering: Which records match my conditions?

Pagination: Which subset of matching records should I return?

HTML and CSS create the user interface. Express.js processes API requests, while a database can filter, count, sort, and paginate records efficiently.

Using filtering and pagination together makes product catalogs, dashboards, search pages, and other data-heavy applications easier to use and maintain.
